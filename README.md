# Python-Salary-Calculator-Beginner-Project:
This is a beginner-friendly Python project that calculates Gross Salary, Tax Amount, and Net Salary based on user input.

🔹 Concepts used:
Variables & Data Types
Arithmetic Operators
User Input Handling

🔹 Features:
Takes salary input from the user
Calculates tax based on a fixed percentage
Displays gross salary, tax amount, and final net salary

This project helped me understand how basic Python concepts can be applied to real-world scenarios.
